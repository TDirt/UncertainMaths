# UncertainMaths
A browser-based decision assistant for entrepreneurs that turns uncertain inputs into Monte Carlo simulations, compares alternatives, and surfaces which variables are most valuable to clarify.

Features:
- Natural-language decision description
- Editable uncertain inputs with uniform, normal, and metalog-style support
- Alternative comparison with expected value, percentiles, probability of best outcome, and regret
- Approximate value-of-information ranking for the most important uncertain variables
- CSV export for sample results
